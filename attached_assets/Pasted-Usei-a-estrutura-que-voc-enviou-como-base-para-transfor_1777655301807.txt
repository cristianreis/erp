Crie um sistema ERP web completo para uma empresa metalúrgica, usando React + TypeScript + Tailwind CSS + shadcn/ui no front-end e Supabase/PostgreSQL como banco de dados, autenticação e backend.

O sistema deve ser chamado: ERP Metalúrgica PCP/MRP.

Objetivo principal:
Criar um ERP funcional para controlar estoque, vendas, PCP, MRP, produção, usinagem, montagem, compras, qualidade, máquinas, operações, clientes e fornecedores.

O sistema deve permitir que a empresa controle produtos acabados, peças fundidas/brutas, peças usinadas, componentes comprados, matéria-prima, produtos em processo, ordens de produção, ordens de montagem, solicitações de compra e pedidos de venda.

IMPORTANTE:
O sistema precisa nascer funcional, com banco de dados bem estruturado, telas completas, CRUDs funcionando, regras de negócio aplicadas, dashboard, relatórios, alertas de estoque baixo, cálculo de disponibilidade, reserva de estoque, baixa automática de estoque na expedição e rotina de MRP básico.

5.1 Cálculo de estoque disponível
----------------------------------------------------

Disponível para venda =
estoque com status disponível em local de produto acabado
- quantidade reservada.

Não considerar:
- produto em processo
- produto reprovado
- sucata

5.2 Pedido de venda
----------------------------------------------------

Na tela de pedido de venda:

- permitir selecionar cliente
- adicionar produtos
- mostrar estoque disponível antes de vender
- mostrar estoque total, reservado e disponível
- mostrar alerta se estoque estiver abaixo do mínimo
- se houver estoque disponível, botão "Reservar estoque"
- se não houver, botão "Enviar para MRP"
- status do item deve indicar:
  disponível,
  reservado,
  falta estoque,
  precisa produzir,
  precisa comprar

Quando reservar:
- criar registro em stock_reservations
- atualizar reserved_quantity em stock_balances
- criar stock_movement tipo reserva_venda

Quando expedir:
- baixar estoque real
- consumir reserva
- criar shipment
- criar stock_movement tipo baixa_venda
- alterar status do pedido para expedido ou faturado

----------------------------------------------------
5.7 MRP básico
----------------------------------------------------

Criar tela "Rodar MRP".

O MRP deve considerar:

- pedidos de venda aprovados e não atendidos
- estoque mínimo
- estoque disponível
- estoque reservado
- ordens de produção abertas
- pedidos de compra abertos
- ficha técnica dos produtos
- lead time do produto

Fórmula:

necessidade_liquida =
pedidos de venda pendentes
+ estoque mínimo
- estoque disponível
- quantidade em ordens de produção abertas
- quantidade em pedidos de compra abertos

Se necessidade_liquida <= 0:
ação sugerida = usar_estoque ou sem_acao

Se produto for comprado:
ação sugerida = comprar

Se produto for acabado e houver componentes disponíveis:
ação sugerida = montar

Se produto for acabado e faltar componente:
explodir ficha técnica e calcular necessidade dos componentes

Se componente for usinado e houver fundido/bruto disponível:
ação sugerida = usinar

Se componente for usinado e não houver fundido/bruto:
ação sugerida = fundir_comprar

Se componente for comprado:
ação sugerida = comprar

O resultado do MRP deve aparecer em tabela com:

- produto
- necessidade bruta
- estoque disponível
- estoque reservado
- ordens abertas
- compras abertas
- necessidade líquida
- ação sugerida
- quantidade sugerida
- data necessária
- botão para gerar OP
- botão para gerar solicitação de compra

A tela deve permitir aprovar o MRP e gerar automaticamente:

- ordens de produção para itens a fabricar, montar ou usinar
- solicitações de compra para itens comprados ou fundidos/brutos faltantes

- data planejada

- operações necessárias
- apontamentos

Ao criar OP a partir de produto com ficha técnica:
- preencher materiais automaticamente.

Ao criar OP a partir de produto com roteiro:
- preencher operações automaticamente.

Fluxo da OP:
Planejada → Liberada → Em Produção → Em Inspeção → Finalizada

Se faltar material:
status = aguardando_material.

Ao finalizar OP:
- dar entrada do produto produzido no estoque
- gerar movimento entrada_producao ou entrada_produto_acabado
- baixar materiais consumidos
- gerar movimentos de saída_producao ou saída_montagem

9. REGRAS ESPECÍFICAS DO ACOPLAMENTO L60
====================================================

Quando vender Acoplamento L60:

1. Verificar estoque acabado PA-ACL60.
2. Se houver disponível:
   - permitir reservar.
3. Se não houver disponível:
   - verificar componentes da ficha técnica.
4. Para montar 1 Acoplamento L60 precisa:
   - 2 Cubos L60 usinados
   - 1 Anel L60 usinado
   - 2 Flanges L60 usinados
   - 1 Lona L60
   - 8 Parafusos M8
   - 8 Arruelas M8
   - 8 Porcas M8
5. Se todos os componentes estiverem disponíveis:
   - gerar OP de montagem.
6. Se faltar Cubo L60 usinado:
   - verificar Cubo L60 fundido.
   - se tiver fundido, gerar OP de usinagem.
   - se não tiver, gerar solicitação de compra/fundição.
7. Se faltar Flange L60 usinado:
   - verificar Flange L60 fundido.
   - se tiver fundido, gerar OP de usinagem.
   - se não tiver, gerar solicitação de compra/fundição.
8. Se faltar Lona, Parafuso, Arruela ou Porca:
   - gerar solicitação de compra.
9. Quando a OP de montagem finalizar:
   - dar entrada no estoque de produto acabado.
10. Quando expedir:
   - baixar estoque acabado.
